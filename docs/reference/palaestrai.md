# PalaestrAI

`flowcean.palaestrai` is the facade for Soft Actor-Critic learning through PalaestrAI. It exports `SACLearner` and `SACModel`.
Install the optional dependencies described in the [installation guide](../getting_started/installation.md) before using this backend.
