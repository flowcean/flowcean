# scikit-learn

`flowcean.sklearn` provides regression learners, scikit-learn model wrappers, and commonly used metrics. The complete classification and regression metric API, including the `MultiOutputMetric` base, is available from `flowcean.sklearn.metrics`.

Classifier wrappers preserve native predictions by default. See [classifier predictions](../user_guide/model.md#classifier-predictions) for binary thresholds and the binary-only probability interface.
